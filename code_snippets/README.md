# Code Snippets Library

## Overview
This library contains code snippets from open-source Godot projects that have been adapted for capability reuse. Use these snippets when implementing features.

## Sources

- **Primary Use**: Character movement, FSM, camera
- **Code Style**: GDScript 4.x, snake_case

### 2. gtibo/Godot-Plush-Character
- **License**: MIT
- **Primary Use**: Character animations, effects

### 3. studiobool/SuperTuxWorld
- **License**: GPL-3.0

### 4. limbonaut/limboai

### 5. ramokz/phantom-camera
- **License**: MIT
- **Primary Use**: Camera system
- **Type**: Plugin (use as-is)

## How to Use

1. Identify the feature you need
2. Find the matching snippet category below
3. Copy and adapt the code to your project
4. Update parameters as needed
